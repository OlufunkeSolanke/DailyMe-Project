# DailyMe — Minimalist Habit Tracker

DailyMe is a beautifully crafted, privacy-focused minimalist habit tracker designed to help you build rituals, track daily consistency, and reach execution milestones without the clutter of traditional apps. Built with an elegant, earthy color palette (Amber, Sage, Rose, Violet, Slate, and Teal), it balances premium editorial aesthetics with highly responsive, utility-driven functionality.

## ✨ Core Features

* **Dynamic Streak & Milestone Engine:** Tracks consecutive consistency blocks using localized day-math. Includes a 21-day milestone tracker to reinforce neuroplastic habit formation.
* **Custom Categorization & Smart Tags:** Group your daily rituals by core areas of life such as **Health & Wellness**, **Business & Career**, or **Mindset & Rituals** with intelligent brand color auto-mapping.
* **Contextual Day Skipping & Archiving:** Pause tracking dynamically on off-days without destroying active streaks, or clean up your dashboard by moving older goals to the secure **📦 Vault** tab.
* **Web Push Notification Scheduling:** Native daily check-in alerts system running directly on browser-level workers to keep execution top-of-mind.
* **Fluid Adaptive Dark Theme:** A fully integrated dark-mode engine that swaps variables cleanly across text field vectors and custom form states without rendering lag.
* **Localized Device Sandboxing:** Securely persists configurations, profiles, and historical logs natively on-device via strict `localStorage` encryption states.

## 🛠️ Built With

* **HTML5 Semantic Markup:** Optimized layout structure built completely with native inputs, responsive containers, and modular data lists.
* **Custom CSS Variables (Vanilla Architecture):** Built from scratch with modular properties, custom SVG background image injection layers, and strict hardware-accelerated fluid layout animations.
* **Vanilla JavaScript (ES6+ Layout Engine):** Event-driven architecture utilizing zero external libraries or heavy dependencies, keeping rendering lightning-fast.
